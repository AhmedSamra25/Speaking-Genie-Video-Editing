Creating your first course

Updated on Aug 2, 2026

A course is the container for everything students practise: levels, and inside each level the tasks, vocabulary and idioms the AI partner uses in conversation.

1. Add the course

Go to Courses and choose Add course. Give it a name, pick the language, choose target audiences and write a short description of the objectives.

2. Add levels

Open the course and add levels from the Levels tab. Each level has learning goals, KPIs, a maximum number of output words and a speaking speed for the AI partner.

3. Or set it up with AI

Choose Set up with AI to generate a plan of levels, tasks, vocabulary and idioms. You can review and edit the plan before applying it.
