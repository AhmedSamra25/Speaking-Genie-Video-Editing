# Speaking Genie — "How it works" voice-over script

**Length:** 47 seconds · **Default language:** Egyptian Arabic with English product terms · **Pace:** calm and warm · **Tone:** confident, conversational, not salesy.

**Recording tips**
- Quiet room, mic or phone about a hand-width from your mouth.
- Say English terms (task, feedback, sessions…) the way Egyptian teachers say them in class — naturally, not with a heavy American accent.
- Say each line once, pause 2 seconds, then the next. I'll cut and place each line on the timeline.
- WAV or M4A preferred (MP3 is fine). Record each language as a separate file.
