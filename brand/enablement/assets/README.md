# Enablement assets

Used by the motion compositions in the Enablement look (`motion/scripts/sync-brand.mjs` copies this folder to
`motion/public/brand/enablement/`).

| File | What | Source |
| --- | --- | --- |
| `logo-lockup-white.png` | white lockup, the only logo allowed on purple | keyed from the team's white-on-black lockup (2000 px master), alpha from luminance |
| `logo-mark-white.png` | white mark alone | keyed from the team's white-on-black mark |
| `badge-app-store.svg` | "Download on the App Store", black, English | Apple's App Store marketing guidelines |
| `badge-app-store-ar.svg` | the same badge, Arabic | Apple's marketing tools (`ar-ar`) |
| `badge-google-play.png` | "Get it on Google Play", English | Google Play badge page, transparent padding trimmed (564×168) |
| `badge-google-play-ar.png` | the same badge, Arabic | Google Play badge page, trimmed |

Badges are shown as supplied: never recoloured, never mirrored, App Store first, on the individual track only.
The logo rasters are good to about 250 px tall; send vector originals for anything larger.
