# UI kit — deck styles

Three house styles, each taken from a real Speaking Genie deck in `uploads/`. `index.html`
is the chooser: what each style is for, when not to use it, and the rules all three share.

| Style | Source | Job |
| --- | --- | --- |
| **Investor** (default) | `Investor Pitch Deck June2026.pdf` | Fundraising, board updates, partner business cases. White, centred, small-caps kicker, one purple word per headline, pastel cards with corner badges. Purple full-bleed reserved for the technology slide and the ask. |
| **Narrative** | `Talent Pitch Deck.html` | Corporate/BPO pitches, centre partnerships. Plus Jakarta Sans, section label top-centre, deliberate dark-photo / light-analysis alternation, one purple turn slide. |
| **Cinematic** | `Aladdin Pitch Deck.html` | Keynotes and vision moments only. Cinzel serif, gold #FFD700, full-bleed vignette, gold-ruled story boxes. |

Three slides per style, 1280×720, type in `cqw` so each holds at any render size.

**Investor is the default.** It is the most recent and the only style carrying verified
figures. Never mix two styles inside one deck.

The seventeen layouts in `../slides/` are layout primitives (agenda, metrics, roadmap,
comparison, team, pricing) that drop into any of these three styles. These three are the
styles themselves.

Photography is a labelled hatched stand-in — this system stores no imagery, and all three
source decks pull from Unsplash. Fine for internal drafts, risky for paid media.
